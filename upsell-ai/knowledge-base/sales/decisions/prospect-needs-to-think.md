# Prospect Says They Need to Think

## Situation

The buyer expresses purchase interest but delays commitment by saying they need more time or more thought.

## Possible interpretations

- An unresolved objection remains.
- The buyer lacks decision authority.
- Too many options or too much information created uncertainty.
- The buyer fears choosing incorrectly.
- The value or urgency is not strong enough.
- The phrase is a polite rejection.

## Recommended action

Respect the request, then ask permission to clarify what remains uncertain. Diagnose whether the issue is value, information, authority, alternatives, timing or outcome risk.

## Decision branches

- If the problem is unclear value, return briefly to the desired outcome.
- If the problem is choice overload, offer one reasoned recommendation rather than more options.
- If the problem is risk, set realistic expectations and use only approved risk reducers.
- If another person must decide, clarify the decision path.
- If it is a polite rejection, close respectfully.

## Avoid

- Increasing fear or pressure automatically.
- Sending more information without knowing what is missing.
- Offering an immediate discount.
- Pretending certainty about outcomes.

## Success criterion

The source of hesitation becomes clearer or the seller obtains an honest close to the conversation.
